# TokenHub 用户门户 Demo

展示用户门户菜单和页面骨架，概览使用固定假数据展示服务余量、用量趋势、告警与公告；用量中心支持统计、筛选、维度汇总、调用明细和详情抽屉；操作审计支持筛选、分页和详情抽屉；其余业务页面为占位内容，无后端请求。

## 运行

```sh
npm install
npm run dev
```

## 构建

```sh
npm run build
```

使用 Vue 3、TypeScript、Vue Router、Vite 和 Lucide 图标。哈希路由可用于静态部署，不需要服务器配置路由回退。

- 所有菜单支持独立路由及刷新。
- 用量中心通过 `?tab=statistics` / `?tab=details` 切换标签。
- 帮助与支持支持展开收起。
- 右上角可切换演示身份；子账户隐藏子账户管理与操作审计。这仅演示导航，不是实际鉴权。
- 支持侧栏折叠和移动端抽屉菜单。
- 后续可将各页面拆为路由组件；当前 App.vue 统一展示布局和占位区。

## 概览演示

- 数据快照固定于 2026-09-28，刷新仅演示加载效果。
- 右上角切换主／子账户；子账户展示个人配额，隐藏告警摘要。
- 可切换近 7 天／近 30 天用量，悬浮或键盘聚焦图表查看精确值。
- 页面场景选择支持正常、空数据、账户受限、计量更新中和额度加载失败（可重试）。
- 服务／告警／公告及快捷入口进入相应占位页，保留详情标识或日期筛选。
- 概览组件：src/components/OverviewView.vue；趋势图：src/components/UsageTrend.vue。

## 操作审计演示

- 地址：`/#/audit-logs`；固定虚构数据日期为 2026-09-28，包含 68 条成功、失败及拒绝事件。
- 支持时间、模块、操作类型、结果、操作人、服务及对象名称／ID／操作编号查询；条件需点击查询后生效。
- 支持每页 20／50／100 条、前后翻页、重置及加载状态。分页使用固定本地数据模拟，不代表生产游标接口已接入。
- 详情抽屉展示历史对象、变更前后值和结果说明，支持编号复制、Esc关闭、键盘焦点约束及 `?logId=audit-0001` 直达。
- 场景：正常、空记录、查询失败（可重试）、部分操作未接入。
- 子账户隐藏菜单；直接访问展示无权限。切换身份清除详情和筛选，仅为展示逻辑，不能替代后端权限校验。
- 组件：`src/components/AuditView.vue`；样式：`src/components/audit.css`；演示数据：`src/data/audit.ts`。

## 用量中心演示

- 地址：`/#/usage?tab=statistics`；支持“用量统计”和“调用明细”两个标签页。
- 公共筛选包括时间、服务、模型、用户密钥和调用账户；明细页增加调用、计量、计费状态及调用编号。
- 统计页展示调用次数、输入／输出／总 Token、已确认消费、每日趋势、缓存输入分析和模型／密钥／账户／服务汇总。
- 汇总记录可钻取调用明细；明细支持分页和详情抽屉，区分调用状态、计量状态及计费状态。
- 右上角切换子账户后，只展示该子账户的 Token 服务调用，隐藏其他调用账户和 AI 应用业务数据。
- 页面场景选择支持正常、空记录、部分计量中和查询失败；固定数据仅用于演示交互。
- 组件：`src/components/UsageView.vue`；样式：`src/components/usage.css`；演示数据：`src/data/usage.ts`。

## 需求文档路由

访问 `#/requirements` 进入独立需求文档页面。页面可切换和搜索 docs 目录中的 Markdown 文档，并使用章节目录定位。文档正文、表格及代码块均支持阅读，文档间的相对链接在页面内切换。该路由不加入用户门户业务菜单，直接引用 ../docs/*.md；新增或修改文档后，开发模式自动更新，静态部署需要重新构建。
